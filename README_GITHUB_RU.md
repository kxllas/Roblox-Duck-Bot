# Roblox Duck Bot — сборка EXE через GitHub

На компьютере пользователя Python не нужен. GitHub соберёт приложение на Windows в облаке.

## Что сделать

1. Войди на https://github.com/ или создай бесплатный аккаунт.
2. Нажми **New repository**. Название, например `Roblox-Duck-Bot`. Выбери **Public** или **Private**, затем **Create repository**.
3. На странице пустого репозитория выбери **uploading an existing file** (или **Add file → Upload files**).
4. Распакуй этот ZIP на компьютере и перетащи ВСЕ файлы и папку `.github` в окно загрузки GitHub. Важно: папка `.github/workflows/build.yml` должна сохраниться с такой структурой.
5. Нажми **Commit changes**.
6. Открой вкладку **Actions** репозитория. Должен запуститься workflow **Build Roblox Duck Bot EXE**. Если нет — открой его и нажми **Run workflow**.
7. Дождись зелёной галочки (обычно несколько минут), открой завершившийся запуск.
8. Внизу страницы в разделе **Artifacts** скачай `RobloxDuckBot-Windows`.
9. Распакуй скачанный архив — внутри будет `RobloxDuckBot.exe`.

## Важно
- Python на твоём ПК не устанавливается: сборка идёт на серверах GitHub.
- При первой загрузке EXE Windows SmartScreen может предупредить о неизвестном издателе — это обычное предупреждение для самостоятельно собранного приложения.
- Приложение использует распознавание по HSV и не гарантирует игру без поражений. В текущей версии автоматическое определение проигрыша/обучение по нему не завершено.
- Для корректной работы Roblox должен быть активным окном; начни с небольшого окна и проверь координаты области захвата.
