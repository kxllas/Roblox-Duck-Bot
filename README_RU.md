# Roblox Duck Bot

## Важно
Это экранный помощник, а не гарантия победы: HSV-детекция может ошибаться из-за эффектов, освещения, анимаций и перекрытий. Адаптивная калибровка пока консервативна: автоматическое определение самого факта проигрыша и обучение на результате зависят от конкретной мини-игры и не могут быть надёжно реализованы без её интерфейса/сигнала поражения.

## Сборка EXE на Windows
1. Установи Python 3.10 или новее с сайта https://www.python.org/downloads/windows/ и отметь **Add Python to PATH**.
2. Распакуй папку в обычное место, например `Рабочий стол\Roblox_Duck_Bot`.
3. Дважды нажми `BUILD_EXE.bat`. Скрипт установит зависимости и соберёт `dist\RobloxDuckBot.exe`.
4. Запускай EXE. При первом запуске Windows SmartScreen может показать предупреждение для самостоятельно собранных приложений.

## Первый запуск
1. Открой Roblox в оконном или безрамочном режиме и оставь игру на переднем плане.
2. Запусти приложение.
3. Укажи `X`, `Y`, ширину и высоту прямоугольника игры в координатах всего экрана.
4. Наведи мышь на заметную часть утёнка и нажми «Запомнить цвет уточки».
5. Наведи мышь на трубу и нажми «Запомнить цвет трубы».
6. Начни с порога 140–170 px и задержки 0 мс. Подстрой значения тестовыми запусками.
7. Нажми «Старт». F8 — пауза/продолжение, F9 — остановка. Аварийная остановка PyAutoGUI — переместить мышь в левый верхний угол.

## Примечания
- В приложении используется MSS и OpenCV; цикл ограничен целевыми 60 FPS (фактическая частота зависит от ПК).
- Клавиша Space отправляется в активное окно.
- Если HSV-цвета объекта похожи на фон, сузь/расширь диапазоны вручную.
- Не запускай от имени администратора без необходимости. `keyboard` может требовать повышенных прав для глобального чтения клавиш на некоторых системах.
- Закрой приложение кнопкой окна или F9 перед выходом.
